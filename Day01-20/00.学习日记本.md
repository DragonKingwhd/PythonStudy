```python
if num >= 90 :
    print(f"优秀")
elif 80 <= num :
    print(f"良好")
elif 60 <= num  :
    print(f"及格")
else :
    print(f"不及格")
```
<!-- 题目说"90 及以上",你写的是 >,90 分这个边界被漏掉了。90 分会掉进 elif 80-89,但 elif 写的是 80 <= num <= 89,90 也进不来——所以 90 分会一路掉到 else 打印"不及格"。
改成 num >= 90 就行。
还有一个思维上的优化,你看出来没?
你的 elif 写的是 80 <= num <= 89,但其实只需要 num >= 80。为什么?

因为能走到第二个 elif,说明第一个 if(num >= 90)已经是 False 了。也就是说 num 一定 < 90。这时候只要 num >= 80,就一定在 80-89 之间——上界 Python 已经帮你卡好了。
这不是"风格问题",这是**"if-elif 链是有顺序的"**这个概念有没有真正内化。你写双边界 80 <= num <= 89 说明你把每个分支当成独立判断了——其实 elif 之间有先后关系,前面 False 才会到后面。 -->

这题难度跳一档,卡住正常,别硬扛超过 10 分钟。
```python
n = int(input("输入一个整数 n:"))
if n % 1 == 0 and n % n == 0 and n % 2 != 0 and n % 3 != 0 and n % 4 != 0 and n % 5 != 0:
    print(f"这个数是一个质数")

    print(f"这个数不是一个质数")
```
更正
```python
n = int(input("输入一个整数: "))
is_prime = True             # 标志,先假设是质数
for i in range(2, n):   # 从 2 试到 n-1
    if n % i == 0:                 # 如果 i 能整除 n
        is_prime = False
        break
if is_prime:
    print("是质数")
else:
    print("不是质数")
```

第 4 关:while 循环(1 题)
任务 8: 写一个猜数字游戏:
程序心里"想"一个数(你自己定,比如 42)
让用户反复输入猜测
猜大了打印"太大了",猜小了打印"太小了",猜对了打印"恭喜!"并结束游戏
提示:用 while True: 配合 break。
```python
num = 42
n =int(input("输入一个数"))
while n != num :
    if n > num:
        print(f"猜大了")
        n =int(input("输入一个数"))
    elif n < num:
        print(f"猜小了")
        n =int(input("输入一个数"))
    elif n == num :
        break
print(f"猜对了")
```
<!-- input 出现了 3 次,代码重复了。
核心思路:while True + break 的模式,就是"无限循环,直到某个条件满足才退出"。每一轮的开头读输入,这样不用在两个地方写两次 input。
你现在的写法不算错,但等你以后写 RL 训练循环,会反复用到 while True: ... if done: break 这个模式——现在就把它练熟。 -->

✅任务 10: 经典题——百钱买百鸡。公鸡 5 元一只,母鸡 3 元一只,小鸡 1 元三只。用 100 元正好买 100 只鸡,有几种买法?把所有买法打印出来。
```python
for i in range(0,21):
    for k in range (0,34):
        z = 100-i-k
        if 5 * i + 3 * k + z/3 == 100 and z % 3 ==0 :
            print(f"{i},{k},{z}")
```
